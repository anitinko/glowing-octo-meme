# HOPLITE — моушен-ролик «я — дизайнер»

56 секунд, 1920×1080, 60 fps, 120 BPM. Ролик целиком сделан кодом: каждый кадр рисуется в Skia
(`@napi-rs/canvas`), музыка и звуковые эффекты синтезируются в Node, ffmpeg всё сводит.
Без шаблонов, стоков и сэмплов.

## Сборка

```bash
npm install
npm run fonts      # Unbounded, JetBrains Mono, Manrope, Playfair Display (с кириллицей) из Google Fonts
npm run build      # → out/hoplite-reel.mp4
```

Нужны Node 20+ и ffmpeg с libx264. Полный рендер — около 17 минут на 2 vCPU, музыка — ~11 секунд.

Для итераций:

```bash
node src/render.js --still 12.5                  # один кадр → out/stills
node src/render.js --sheet 8:12:0.25 --cols 4    # контактный лист → out/sheets
node src/render.js --video --from 36 --to 44 --scale 0.5 --out out/preview.mp4
node src/audio/synth.js --out out/music.wav --stems --stats   # микс + стемы + громкость по секциям
node src/audio/analyze.js out/music.wav                       # LUFS, true peak, тишина перед дропом, сетка бочки
```

## Сценарий

| Время | Сцена | Что происходит |
|---|---|---|
| 0–4 | Интро | Редактор кода: `me.role = "инженер"` переписывается на `"дизайнер"`, все символы схлопываются в красную точку |
| 4–8 | Дроп | Взрыв в «HOP/LITE», затем словарная статья «гоплит», третье значение — «Дизайнер.» |
| 8–12 | 01 Сетка | Красный кадр делится на 12 колонок, блок рисуется, тащится и прилипает к сетке, редлайны |
| 12–16 | 02 Вектор | Перо рисует коринфский шлем по узлам Безье, клики по шестнадцатым |
| 16–20 | 03 Шрифт | «Аа» меняет гарнитуру каждую долю, метрики меряются живьём, панграмма, насыщенности |
| 20–24 | 04 Цвет | Полосы палитры, «рулетка» hex-кодов, перестановки в долю, заголовок в режиме difference |
| 24–28 | 05 Движение | Редактор кривых: linear → cubic-bezier(.85,0,.15,1), сквош-стретч |
| 28–32 | 06 Система | 15 UI-компонентов собираются фалангой, волна переключает состояния |
| 32–36 | 07 Вдох | «пиксель к пикселю» → «щит к щиту», отсчёт 4-3-2-1 |
| 36–44 | 08 Всё сразу | 16 карточек по одной доле: бренды, интерфейсы, иконки… и код |
| 44–48 | 09 Знак | Построение логотипа по золотому сечению, локап |
| 48–56 | 10 Финал | Подпись на красном, всё сворачивается в курсор редактора |

## Устройство

- `src/timeline.js` — единый источник правды для картинки и звука: окна сцен, удары, главы, звуковые cue.
- `src/scenes/*` — сцены; каждая экспортирует `draw(ctx, localTime)`, `blur()` (сколько субкадров
  моушен-блюра нужно в момент времени) и `cues` для синтезатора.
- `src/render.js` — рендер кадров, моушен-блюр через временной суперсэмплинг (затвор 180°),
  тряска/вспышка/RGB-сдвиг на ударах, вывод в ffmpeg (BT.709).
- `src/lib/helmet.js`, `src/lib/emblem.js` — знак: шлем хранится как опорные точки Безье, поэтому
  его можно «рисовать пером» узел за узлом.
- `src/audio/*` — синтезатор: партитура (ре минор), барабаны, басы, пэды, арпеджио, лид, SFX по cue,
  реверб, сайдчейн, мастеринг до −14 LUFS.
